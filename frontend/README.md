# Pizzería Mamma Mía - Hito 5

Aplicación React + Vite con navegación mediante React Router.

## Instalación y ejecución

```bash
npm install
npm run dev
```

La aplicación consulta el catálogo y el detalle de la pizza al backend, que debe estar activo en `http://localhost:5000`.

## Rutas implementadas

- `/` - Home
- `/register` - Registro
- `/login` - Inicio de sesión
- `/cart` - Carrito
- `/pizza/p001` - Detalle de la pizza p001
- `/profile` - Perfil estático
- `/404` - Página no encontrada
- Cualquier ruta desconocida muestra la página NotFound.
